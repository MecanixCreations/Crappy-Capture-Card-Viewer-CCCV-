# Crappy Capture Card Viewer
very barebones webpage to allow you to display the output of a capture card on web locked devices like chromebook. It also resizes the image to 16:9 if that isnt working normally as some cheap capture cards can display funkily on chromebooks due to a worn out usb port or otherwise.

click the webpage a couple times till a permission popup shows, then allow it to use the capture card, often labeled "USB 3.0 Video"
